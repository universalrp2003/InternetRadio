# Live Guard / CleanSweep 2.34 — charging display and security fixes

## Fixed

- **Charger connected: watts only.** The floating status pill hides mobile-data/5G
  text, D/U network LEDs and pack-quota flashing. Its window is remeasured so hidden
  indicators do not leave a wide, overlapping layout. Missing power is `— W`, not
  a guessed number or an amps/battery-percent substitute. Watts are battery-side,
  not the charger's rated output.
- **Unplug: restore the normal live view.** An enabled background monitor is no
  longer unconditionally stopped by the unplug receiver. Data/LED display and the
  user's Wi-Fi/unlimited-5G, position and scale preferences return unchanged.
  Charging-only mode still stops on unplug; no persistent monitoring is silently enabled.
  Cancelled/outdated display updates cannot redraw the old pill after a quick plug/unplug or Stop.
- **Fix / Manage targets the actual issue and app.** Findings retain exact package
  and service-component IDs. Manage opens the selected app's relevant settings;
  multi-app Fix/review asks which app. SMS, device admins, app reviews, screen lock,
  Developer options and system updates no longer fall through to Settings home.
  MIUI/HyperOS candidates have guarded fallbacks and explicit manual paths.
- **Ask AI includes all current issues.** The security button now requests a fresh
  inventory, security, battery and storage report from the selected AI, with all
  findings/evidence/manual hints and all affected apps when sharing is enabled.
  It also includes available, dated malware/junk/LAN results and optional current
  network/data observations. App-name and network-sharing switches are respected.
  No SMS, contacts, file paths, files or private AI keys enter this report, and no
  web search is made with its phone findings. The complete outgoing text is inspectable;
  retry/re-analysis preserves security-focused mode.
- Removed advice that treats a heuristic 100/100 score as proof of safety or asks
  users to disable legitimate banking/accessibility services just to improve it.

## Downloads

Install `CleanSweep-v2.34.apk` (the launcher name is **Live Guard**). It uses the
same application ID/signing key and updates v2.33 without an uninstall.
Ramesh Radio **1.8** and PulseEQ **1.2** are unchanged maintained-app companions.
AABs are included for submission workflows; install the APK, not the AAB.

## Validation and limits

Publication is gated on CleanSweep debug/release unit tests (27 new regression
cases), existing Radio tests, debug/release compilation, AAB generation, and APK,
manifest, non-debuggable, API-26/version and enforced project-certificate checks in
GitHub Actions. A report gate rejects missing/skipped required regression suites.

[Publication checks passed in GitHub Actions](https://github.com/universalrp2003/InternetRadio/actions/runs/38059390123).
No physical phone/emulator was available in the coding environment. After publication,
the owner confirmed correct charging/display behaviour on **Redmi 13 5G** and
provided screenshots: watts-only while connected, normal data/D/U display after
unplugging, and the corresponding charging/normal notification cards. Android and
MIUI/HyperOS versions were not supplied. This is a limited user-confirmed result,
not a full device-plan pass or certification of other phones, Security routes or AI.
Other models, OEM settings shortcuts and the remaining overlay/background cases
still need the checks in
[`docs/live-guard-2.34-device-test-plan.md`](https://github.com/universalrp2003/InternetRadio/blob/arena/5cb8f828-internetradio/docs/live-guard-2.34-device-test-plan.md).
Android restricts third-party accessibility detail links and, on Android 11+,
per-app overlay links: a correct category plus named instructions is the honest
fallback, not an automatic permission fix. AI advice can be wrong and cannot
change system settings for you. GitHub publication is not app-store approval.
