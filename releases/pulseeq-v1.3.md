# PulseEQ 1.3

Stable direct-download APK for PulseEQ.

## Highlights

- Tamil is the default interface language, with an in-app switch to English.
- About now provides contributor credits and direct links to all four app releases.
- Adds verified GitHub release checks and APK hand-off to Android. The updater checks the package, version, SHA-256 digest and signing identity before installation.

## Installation and safety

Download `PulseEQ-v1.3.apk` and install it through Android. If Android requests it, enable **Allow from this source** for the browser or file manager you used, then confirm the installation in Android's installer. No silent install or Play Protect bypass is used. Audio processing remains on-device.
