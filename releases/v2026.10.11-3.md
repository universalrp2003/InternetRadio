The owner authorized the next build and publication on **11 October2026**.
This new release candidate is **CleanSweep2.39 / versionCode44**. The workflow
publishes it only after regression tests, all-module compilation and release

## Why this supersedes the first2.38 publication

2.38 passed CI38142967677 and was published immutably. Its universal APK measured
**82,630,093 bytes**, exposing the updater's50MiB cap.2.39 fixes size handling with
**128MiB cap**, compresses/extracts native libraries while retaining allABIs, and
adds a CI gate on the actual delivered APK size. The delivered successor must also fit the existing2.38 client's50MiB cap;
that compatibility is checked against the actual APK before publication.
No2.38 asset is overwritten.
Unchanged Radio1.8/EQ1.2 companions are carried **byte-for-byte from verified2.37**,
not the nondeterministic rebuilt copies from2.38. Full regression/signature gates
run again for2.39 before this new tag can publish.

## What's changed

### Guided, reviewed setup

- Home feature setup and directory explain safe local readings, missing Android
  access, incomplete configuration and optional OFF choices separately. Apply
  writes only choices explicitly edited in the review; saved OFF choices persist.
- Permanent monitoring, charging foreground card, background Wi-Fi scan and voice
  are OFF when no choice is saved. Sensitive permissions are explained/requested
  through Android, not silently granted. Existing explicitly saved preferences
  remain in effect. Optional aggregate setup notifications are OFF by default,
  quiet, at most daily and do not nag about deliberately OFF/skipped functions.
- Automatic online daily summaries have separate explicit consent, default OFF,
  honor allowed app-name facts and may use provider quota. Local checks and
  manually requested AI reports are separate actions. No notification content
  joins those reports.

### Home Update — browser-free download with Android confirmation

- Home Update pulses only for an eligible newer stable official **published
  release's metadata**, not unpublished CI builds. Optional daily-on-launch and
  manual checks respect the existing automatic-check OFF choice.
- Explicit in-app APK download with progress/cancel and a180-second deadline,
  one streaming worker, bounded size and HTTPS GitHub delivery-host redirects.
  No background/unverified automatic installation.
- Require official repository/tag/asset URL, published SHA256/size and downloaded
  bytes; recheck package, higher installed version code, version name and matching
  stable installed signing certificate before installer handoff. FileProvider
  exposes only the private verified-update cache directory.
- Explain Android **Install unknown apps** access and provide the app-specific
  permission route. Android installer confirmation is mandatory. Android controls
  actual signature verification, Play Protect/scanning and installation outcome;
  no silent install, bypass or forced-scan guarantee. Release notes remain
  identified publisher text, not automatically translated instructions.
- Ramesh Radio/PulseEQ shared updater is unchanged. Users of2.37 must first install
  this APK from the release link; the new in-app path is inside2.39 for future releases.

### Selected notification reader — opt-in and local

- Explicit app multi-selection and optional app-scoped sender-name multi-selection,
  including manually entered names and bounded session candidates. Names supplied
  by notifications are not verified contact identities; no Contacts permission.
- **Sender name only** by default; separate full-message switch per app. Speech
  contains sender/content only, not app name, timestamp, count or a ribbon.
  Android notification access is broad and must be reviewed/granted by the user.
  Turning reading OFF stops speech; revoke system access separately in Android.
- Fresh notification/message timestamps only; no existing-notification replay.
  Group summary/call/ongoing/progress/aggregate filters, coalescing, deduplication
  and bounded queues. Suspected OTP/password suppression is heuristic, not proof
  that every sensitive message is recognized.
- Default screen-on/unlocked-only, DND/config/language/freshness start checks and
  cancellation on lock/disconnect/choice changes. Android redaction, force-stop,
  process survival, volume/quiet hours and OEM restrictions can still suppress
  delivery. Speech completion is not proof sound was heard.
- Bundled **local language identification** and consented **on-device EN/TA
  translation** models. Model download is explicit, Wi-Fi by default. Unsupported/
  unknown language, missing model or translation failure means sender name only:
  **no private message AI/online-translation fallback**. Notification speech uses
  an installed voice reported as non-network, never an online speech fallback;
  the external TTS engine's own implementation/privacy policy still applies.
- No message/audio/history persistence or content in voice diagnostics/AI reports.
  Explicit selected app/sender rules stay privately on this phone and can be cleared.
  Candidate names/fingerprints are bounded session memory. A consented ML Kit model
  download may finish after leaving the page; its physical cancellation is not promised.

### Official key help, dates and actual voice selections

- Nearby official provider/VirusTotal key/help links and bilingual text/voice guides.
  Guides never read API keys; account access, billing and free quotas are not promised.
- 12-hour AM/PM displays and selected app-language notifications; real saved
  permission-review date/count/unknown/incomplete/clock-changed states and Clear.
  Loading a saved summary does not create a new review or safety verdict.
- Two actual installed, selected and previewed per-language A/B answer voices
  alternate **between answers**, one automatic utterance per answer. No inferred
  gender, answer replay or cross-voice retry to simulate two different people.
  Missing language voices stay unavailable; manual previews do not enable reading.

### Compact launcher widgets, not a floating-pill redesign

- Three compact **2×2 target** launcher entries: Battery, Data, Phone. Each has a
  per-instance View selector, coalesced IO refresh and48dp controls. Launcher cell
  dimensions/font scaling vary; resize/re-add old widget instances if required.
- Current actually reported battery, **last observed power-disconnect time and
  available level**, not a timestamp invented when opening an already-unplugged
  app. One clearable aggregate is separate from opt-in charging history. Missed
  events remain unknown or explicitly last-observed, not actual-latest guarantees.
- Metered mobile usage/remaining only when available/user-configured; no guessed
  default allowance in the new widget. Wi-Fi/user-set unlimited5G gets useful
  phone/storage details instead. “Unlimited5G” is the user's setting, not carrier
  billing evidence. Partial/unavailable stats and phone-clock anomalies are labelled.
- The floating status pill keeps its existing charging-watts/unplug behavior.
  Normal integer-resolution phones do not get fabricated high-decimal battery values.

### Cancellable AI and evidence — no hidden provider change

- One45-second chat budget includes8-second web lookup, progress/elapsed/cancel,
  no stale-result delivery and no silent chosen-provider-to-Free fallback. Free
  tries at most two endpoints, not indefinite retry loops. Checks/models use15 seconds.
- Heavy report preparation+provider and scan/device-AI each have owned90-second
  operation limits, progress/cancel and navigation/provider/language invalidation.
  Four detached local-read owners cap blocked Android work; late results are dropped.
  Native Binder/DNS work may finish later and cannot be forcibly killed.
- Scan+AI uses **one batch request**, not90 seconds per device. Network-sharing OFF
  is honored, Wi-Fi network name omitted and AI guesses remain labelled text, not
  automatically saved user names/verified hardware fingerprints.
- Mode-aware local welcomes, stable localized/sanitized provider errors, structured
  native grounding sources and requested-model—not execution-proof—metadata.
- Exact-product price gates prevent Redmi13 5G questions using Redmi12/13C/4G or
  Wikipedia guesses as current seller prices. TODAY-only phone-local dated/deduped
  EN/TA news remains; no old/fake/safety-filler fallback or publisher ribbon.

### LM Arena rating card — exact, sourced and honestly dated

- Optional official `lmarena/arena-catalog` overall-text `full` source refresh,
  immutable file-commit/blob verification and exact model ID matching on the phone.
  Source/fetch dates and published confidence interval are distinct. Selected model
  and API key are not sent in the public-source request.
- The independently verified public feed is **11 December2025**, NOT proof of a
  live October2026 score. Older-than-seven-day/future-clock data is explicitly
  dated; ambiguous/routed/no-match IDs remain unavailable. No namespace/free/
  preview suffix stripping to force a score. A live-site/source link is provided.
- Crowd preference is **not IQ, universal intelligence, Tamil quality or proof
  that the configured model actually executed**. No invented Gemini3.8/routed score.
