## The fix: a zero is never a measurement

2.42 added a fallback that reads the battery broadcast's `current_now` extra when the documented
current property reports 0 or "unsupported". On the owner's **OPPO A3s** (Android 8.1 / ColorOS)
the owner then checked the charging card and reported: **still 0.00 W**. That result is
diagnostic — on that kernel *both* paths answer zero, so there is no current to rescue, and
2.42's mistake was to treat a broadcast zero as a *measured trickle* and print `0.00 W` again.

A zero from both sources is indistinguishable from an unsupported sensor, and the standing rule
is that an unsupported sensor must never be rendered as a measured `0.00 W`. So from 2.43:

- a **non-zero** value from the property is used (Android's documented counter);
- otherwise a **non-zero** value from the broadcast extra is used (the fallback that rescues
  kernels whose property lies);
- otherwise the current is reported as **not reported** — on the A3s and everywhere else.

What this means on each phone:

- **OPPO A3s:** the charging card will show *not reported* for current and no watt figure,
  instead of the fake `0.00 W` / `-0.00 A`. The rest of the card (percentage, voltage,
  temperature, charge history) is untouched. No app can show real watts on a kernel that reports
  no current through either Android path; what it can do is stop pretending, and that is what
  this is. **One screenshot from the A3s while charging will confirm the new wording.**
- **Redmi 13 5G and any phone with a working counter:** unchanged. A working counter reports a
  trickle as a small *non-zero* value, so genuine low-current charging still shows real watts;
  only the impossible "exactly zero microamps" reading disappears.
- Watts still come from exactly one place, units still from exactly one place, and the
  screen-on/off note, the 44 °C warning and the charge history are untouched.

New regression tests hold the rule: zero from both sources is `NONE` with no watts; a small
non-zero value is still used; an implausible 50 A is still refused.
