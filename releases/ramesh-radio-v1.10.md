# Ramesh Radio 1.10

Verified bridge APK for the standalone Ramesh Radio app. It keeps the existing InternetRadio release source as a fallback while adding RP-Android-Apps as the preferred source for verified updates.

## Highlights

- HTTPS station streams are preferred. Existing HTTP stations remain supported with a clear legacy-HTTP warning.
- Custom-stream guidance and the refreshed remote station catalog remain available; radio streaming and update checks use the network, while user-selected local audio is not uploaded.
- Update discovery checks RP-Android-Apps first and InternetRadio second. APK digest, package, version, canonical HTTPS release URL and signer are checked before Android's installer is opened.

## Installation and safety

Download `Ramesh-Radio-v1.10.apk` and install it through Android. If Android requests it, enable **Allow from this source** for the browser or file manager you used, then confirm the installation in Android's installer. No silent installation or Play Protect bypass is used.
