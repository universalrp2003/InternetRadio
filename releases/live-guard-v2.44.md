# Live Guard 2.44

Stable direct-download APK for Live Guard, formerly CleanSweep.

## Highlights

- Tamil is the default interface language, with an in-app switch to English.
- Adds launch-time GitHub release checking and a verified APK hand-off to Android. The updater checks the package, version, SHA-256 digest and signing identity before opening Android's installer.
- The About screen credits project development and AI software assistance, and links to the four app release pages.

## Installation and safety

Download `CleanSweep-v2.44.apk` and install it through Android. If Android requests it, enable **Allow from this source** for the browser or file manager you used, then confirm the installation in Android's installer. No silent-install or Play Protect bypass is used.

**Device testing:** This exact CI-generated APK was not installed on a phone during this release run; no physical-device test is claimed for these release bytes. Publication followed the repository's release checks and the existing permission-delta gate. This statement is not a Play Protect or all-device compatibility claim.
