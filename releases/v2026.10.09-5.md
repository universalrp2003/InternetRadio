# Android app updates — v2026.10.09-5

### CleanSweep v2.24
* **Dynamic Status Bar Data Count Icon**: Rather than showing only static arrows in the status bar (top left next to the clock), the notification icon dynamically generates a real-time numeric readout of today's mobile data usage (e.g. `106 M` or `1.5 GB`).
* **Status Bar Pill Integration**: When the status bar overlay pill is enabled, it renders today's mobile data count (e.g. `106.1 MB` or `1.45 GB`) directly in the status bar area alongside charging wattage.
* **Variable GB Data Pack Management**: Set custom pack size (1.5GB, 3GB, 6GB, 12GB, etc.) and reset recharge counter to 0 MB.
* **Strict Mobile Cellular Tracking**: Strictly isolates mobile networks from Wi-Fi.
