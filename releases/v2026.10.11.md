# Live Guard / CleanSweep 2.36 — phone-age estimate restored

## Restored on Home

The owner's **Estimated phone age** badge is back beside **Live Guard readings**
on the active Home dashboard. It is no longer stranded in an unused storage card.
The title/badge wrap for narrow screens and larger fonts; English/Tamil values
wrap rather than disappear. Tap the badge for the estimate's basis and limitations.
The owner's instruction to retain this feature in future updates is now in `AGENTS.md`.

This is a **coarse model-family/initial-Android-generation estimate**, not the
manufacture, purchase or first-use date of this individual handset. Reference
months are approximate, not verified official launch dates. Best-effort factory
API properties can be unavailable or modified on an OEM/custom ROM. Unsupported,
missing or future evidence says **Not enough information**, not an invented 2022
baseline or “new device”. Updated Android/vendor SDK, security patch and uptime
are not used as proof of phone age. Calculation runs off the UI thread and is
cached in memory per local calendar day, with no new permission, network request,
saved age history or background service.
