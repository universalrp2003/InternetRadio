# CleanSweep v2.18 & Updates (2026.10.08-5)

### CleanSweep v2.18 Highlights
- **Dual-Mode App Network & Tracker Inspector**:
  - **Local On-Device VPN Mode**: Added a switchable local loopback `VpnService` that intercepts outgoing packets and DNS domain lookups directly on-device with zero external routing, reliably displaying destination IPs, remote ports, and telemetry trackers even on Android 10+ where SELinux restricts `/proc/net/tcp`.
  - **Passive / NetworkStats Mode**: Retains non-VPN socket inspection and active data transfer accounting via `NetworkStatsManager`.
- **Background Wi-Fi Scanner (15-Minute Interval)**:
  - Integrated `WifiScanWorker` with `WorkManager` to run periodic checks every 15 minutes when connected to Wi-Fi.
  - Automatically identifies new unrecognized devices and issues Tamil voice alerts ("எச்சரிக்கை! உங்கள் வைஃபை நெட்வொர்க்கில் ஒரு புதிய சாதனம் இணைந்துள்ளது") and notifications.
- **Friendly Device Naming & Verification**:
  - Wi-Fi scan list allows assigning custom friendly labels (e.g. "Living Room TV", "Home Phone") to remembered MAC addresses alongside the green verified tick.
- **Home Screen Clutter Removal**:
  - Removed "Daily brief" card from the Home screen.
  - Removed "Last clean: X freed" bottom card from the Home screen.
- **Targeted Security Spoken Warnings**:
  - Spoken announcements for security checks now trigger exclusively when high or medium risk vulnerabilities are detected, remaining silent when the phone is secure.
