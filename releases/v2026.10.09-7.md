# Android app updates — v2026.10.09-7

### CleanSweep v2.26
* **Universal Wi-Fi Device Verification (Tick Mark & Renaming on All Phones)**: Wi-Fi device verification and renaming now use IP address fallback when MAC addresses are hidden by newer Android privacy restrictions (Android 10+), enabling the green verified checkmark `✓ Verified` and custom renaming buttons to appear on Xiaomi, Redmi, and all phones just like Oppo A3s.
* **Mobile Data Window Moved to Main Screen**: Placed a prominent, clean card on CleanSweep's home screen right below storage, displaying Today's Mobile Data, pack balance remaining, quota progress bar, and quick action dialogs.
* **Unlimited 5G Pack Switch**: Added a dedicated switch for users with unlimited 5G plans to disable pack quota countdown and daily usage counters, seamlessly pausing balance warnings.
* **Persistent Settings Storage Across Updates**: Double-persisted custom data pack quota limits and baseline timestamps across SharedPreferences files, preventing settings from resetting to default on app updates.
