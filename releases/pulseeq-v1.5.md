# PulseEQ 1.5

A verified migration-visibility update for PulseEQ. `RP-Android-Apps` is checked first and `InternetRadio` remains a fallback during the grace period; the About and update screens now identify the source of an available release.

## Highlights

- No equalizer or audio-processing behavior changed in this release.
- The updater identifies the repository that supplied an available release and explains the new-first/old-fallback order.
- Android's per-app install permission and confirmation remain required; Play Protect is not bypassed.

## Installation and safety

Download `PulseEQ-v1.5.apk` and install it through Android. If Android requests it, enable **Allow from this source** for the browser or file manager you used, then confirm the installation in Android's installer. No silent installation or Play Protect bypass is used.
