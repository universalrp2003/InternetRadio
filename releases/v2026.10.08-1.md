# Android 8+ app updates — 8 October 2026 (Revision 1)

For Android 8.0 (API 26) and newer, across manufacturers. Device-dependent features
are labelled; universal device testing is not claimed. Install the release APK
for your app over the existing installation. AAB files are for store submission,
not installation on a phone. This is a GitHub release, not a Play Store listing.

## CleanSweep 2.14
- **Accurate battery-side power & honest widget state**:
  - Distinguishes battery-side electrical power from wall charger output.
  - Power in watts is calculated and displayed only while actively charging on external power; discharging state is honestly displayed as "Discharging" without showing power spikes as charger wattage.
  - Home-screen widget displays real-time `updated HH:mm` timestamps and status.
- **Optional persistent background monitoring**:
  - Added user toggle in Settings for persistent battery & health monitoring with a visible "Stop" notification action.
  - Transparently documents Android 8+ OEM background power limits (cannot survive force-stop).
- **Tamil voice alerts**:
  - Brief, spoken alerts strictly in Tamil for charging started, slow charging, battery full, low battery, and device overheating.
  - Only announces estimated time to full when a reliable numeric estimate is available.
  - Optional "Louder voice alerts" toggle in Voice Settings that temporarily boosts speech volume during alerts without permanently changing media volume.
  - Full respect for Quiet Hours and Do Not Disturb (DND).
- **Compact home header**:
  - Replaced the tall multi-line wrapped title with a clean, single-line compact header.
  - Relocated lengthy multi-device compatibility descriptions into the About screen.
- **Tamil information strip**:
  - Home-screen live information strip featuring dated, attributed Tamil news and cybersecurity alerts.
  - Equipped with Pause/Play, Refresh, and Hide controls, with screen reader accessibility descriptions.
  - Caches items to minimize cellular data consumption.
- **Normalized Gemini AI readiness & model matching**:
  - Normalizes model IDs (e.g. `gemini-3.8-flash`) and does not assume a model is unusable solely because it is absent from a listing endpoint.
  - Falls back to direct probing and clearly identifies the model and provider that answered.
- **Greeting lookup bypass**:
  - Skips unnecessary web searches for conversational greetings ("hi", "hello", "வணக்கம்").

## Ramesh Radio 1.7
- Fix file-picker return/controller-reconnection race: retain the selected file until
  playback connects rather than silently dropping it. Show readable names and access errors.
- Choose a persistent music folder; Previous/Play/Pause/Next follow the active queue.
- Stereo left/right balance with centre reset; mono is unchanged.
- Embedded other-app EQ for compatible sessions; optional global-mix attempt may be
  blocked by Android. Disable competing equalizer apps when testing.
- Reconnect stopped or stale radio streams, bound connection delays, preserve local tracks.
- AI vocal separation/karaoke is NOT included. Neither offline nor online separation is
  implemented yet. Live streams, file providers and vendor EQ still require device testing.

## PulseEQ 1.2
- Manual GitHub update checks and optional daily checks on app launch, with release notes.
- About version matches the installed app, with a source-code action.
- Audio processing stays local. Internet permission is used for release checks.

## Privacy and compatibility
No automatic APK installation. Downloading an update is your choice.
AI and news queries require network access when enabled. Update checks contact GitHub.
See PRIVACY.md. AppForge and the original Internet Radio remain legacy projects;
they are not included in this release.
