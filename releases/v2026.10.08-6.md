# CleanSweep v2.19 & Updates (2026.10.08-6)

### CleanSweep v2.19 Highlights
- **Crash-Free Local VPN Setup & Permission Flow**:
  - Automatically invokes system `VpnService.prepare()` dialog when turning on Local On-Device VPN Mode so Android can prompt for user confirmation.
  - Set TUN file descriptor to non-blocking with safety yield delay, preventing service startup crashes or app closes.
- **Massive 50–100 News Pool & Dynamic App Security Alerts**:
  - Expanded feeds from Tamil Nadu (தினத்தந்தி, தினமணி, News18), India, International (BBC Tamil, Oneindia), and national cyber alerts.
  - Automatically identifies installed applications with high/medium security risk permissions (such as non-banking apps holding SMS access or suspicious overlay permissions) and injects them directly as prominent danger alerts into the news strip.
- **Direct AI Question Field & AI Ready Box Removal**:
  - Removed the bulky "AI ready" status card from the Home screen.
  - Added a direct input field into the "Ask the assistant" card on the Home screen to type and submit questions immediately.
- **Single Centralized AI Phone Analysis**:
  - Cleaned up repetitive "Analyse with AI" buttons across individual screens (Health, Security, Network).
  - Consolidated into one central "AI phone analysis" card on the Home screen that provides a complete, unified assessment.
- **Widget Refinements**:
  - Replaced the "Read brief" button with an expanded, full-width touch-friendly "Clean" button.
  - Updated Voice & daily watch settings to explicitly describe high/medium risk security alerts.
