# Ramesh Radio 1.9

Stable direct-download APK for the standalone Ramesh Radio app.

## Highlights

- Tamil is the default interface language, with an in-app switch to English.
- About now provides contributor credits and direct links to all four app releases.
- Adds verified GitHub release checks and APK hand-off to Android. The updater checks the package, version, SHA-256 digest and signing identity before installation.

## Installation and safety

Download `Ramesh-Radio-v1.9.apk` and install it through Android. If Android requests it, enable **Allow from this source** for the browser or file manager you used, then confirm the installation in Android's installer. No silent install or Play Protect bypass is used. Radio streaming and update checks use the network; user-selected local audio is not uploaded.
