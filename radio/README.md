# Tamilnadu FM Radio v1.0

Tamil FM, world news and a 10-band equalizer in one app — built by **Ramesh prathap .R**.

Module `:radio` • package `com.universalrp.tamilnadufm` • Android 8.0+ (API 26) • sideloaded APK

Get the APK from **Actions → Build APK → the `tamilnadu-fm-radio-apk` artifact** on the branch that
built it. Unsigned-by-Play: install it over an older copy of itself (same CI keystore as the other
apps in this repo), or uninstall the old one first if you installed a differently signed copy.

## What it does

| Screen | What is there |
|---|---|
| **Radio** | Tamil FM stations from Tamil Nadu, Sri Lanka, Malaysia, Singapore, the UAE, UK, USA, Canada, Australia and South Africa. Search box (name, city, language), category chips, star favourites, "Continue listening", and a **Live directory** search that talks to the open Radio-Browser directory from your phone. |
| **News** | Tamil news, Indian news and world news in English, with one-tap live directory searches for more. |
| **Local** | Plays audio files already on the phone (MediaStore scan with permission, or a single file through the system picker) through the same equalizer. |
| **EQ** | A real **10-band equalizer: 31, 62, 125, 250, 500 Hz, 1, 2, 4, 8, 16 kHz**, ±12 dB per band, 16 presets (Tamil FM, Old songs, Music, Movies, Speech/News, Podcast, Vocal, Bass boost, Treble boost, Devotional, Rock, Pop, Jazz/Classical, Dance, Night, Flat), quick-curve chips, preamp with automatic anti-clipping, and the **Clear sound** section. |
| **More** | Sleep timer (15/30/60/120 min), **My stations** (add any stream link), and About with the author credit. |
| **Widget** | A home-screen widget showing the current station with play/pause, previous and next. It talks to the playback service directly, so it works with the app closed — and play resumes the last station. |

**Clear sound / "clear sound without noise"** is four honest things, not a magic button:

- **Clear sound** — gentle multiband levelling plus a limiter, so loud ads and jingles stop
  distorting and quiet dialogue stays audible.
- **Rumble cut** — rolls off everything below 62 Hz, which is where traffic, footsteps, wind and
  handling noise live.
- **Hiss cut** — trims the top octave where low-bitrate streams put their hiss.
- **Volume boost** — a modest loudness enhancer for quiet streams.

Background playback, the media notification, lock-screen controls, headphone buttons and audio focus
are Media3/ExoPlayer; the app keeps playing with the screen off, and pauses when you unplug
headphones.

## Where the stations come from

1. **A seed list inside the APK** (`src/main/assets/stations_seed.json`) so the app works the first
   time you open it, in one request-free list.
2. **A hand-picked list of popular stations** (`tools/curated_stations.json`: Hello FM, Suryan FM,
   Radio Mirchi, Radio City, BIG FM, AIR FM Rainbow/Gold, Shakthi FM, Sooriyan FM, Minnal FM,
   Raaga, Oli 96.8, Lankasri, Yarl FM, ILC London, Tamil 89.4 UAE …). **Every URL in that file is
   probed by CI** when the seed is regenerated — only the ones that actually answer with audio or a
   valid HLS playlist are shipped, and they are marked *verified*. A dead link is dropped, never
   shipped.
3. **The live directory** — `de1/de2/nl1/at1.api.radio-browser.info`, searched straight from the
   phone when you tap **Live directory**. No server of ours in the middle, no API key, no account.
4. **Your own stations** — *More → My stations*, any `http(s)` stream link.

The seed list is regenerated by `.github/workflows/refresh-stations.yml` (monthly, on demand, or
whenever the fetcher or curated list changes) and committed back to the repository.

Honest limits: the directory is community maintained, so a station can go offline without notice.
Rows the directory has not health-checked are marked with a small warning triangle; if a stream will
not play, the app says so and suggests another. Government/private FM broadcasters in India do not
publish official stream URLs for every station, so a few frequencies you may know (some AIR locals)
simply are not streamable anywhere — the app does not invent them.

## Equalizer — what actually applies where

| Path | Supported? | Notes |
|---|---|---|
| Online stations in this app | **Yes** | Effects attach to the app's own audio session. |
| Local files in this app | **Yes** | Same session, same curve. |
| Other apps (YouTube, Spotify, …) | **No** | Android gives no app a way to reshape another app's audio without root or a screen-capture consent dialog. Nothing here fakes that. |
| System-wide | **No** | Same reason. |

The chain itself: on Android 9+ it is `DynamicsProcessing` — 10-band EQ with the app's exact band
curve, a 3-band compressor and a limiter. On Android 8 the app falls back to the classic
`Equalizer` + `BassBoost` + `LoudnessEnhancer` effects, and the EQ screen says so (the engine name is
shown under the power switch). No root, no hidden APIs.

## Honest feature table

| Claim | Reality |
|---|---|
| Tamil FM stations | Shipped seed + curated probed list + unlimited live directory search. |
| Worldwide English news | Shipped seed + directory search (BBC World Service, NPR, DW, Al Jazeera, ABC, CBC, WNYC …). |
| Tamil news | Seed + directory search (`Tamil news` chip). Coverage depends on what the directory carries. |
| Local audio player | Yes: MediaStore library scan, per-file picker, plays through the equalizer. |
| 10-band equalizer | Yes, 31 Hz – 16 kHz, for this app's audio. |
| Clear sound / no noise | Real processing: levelling, limiter, rumble cut, hiss cut. It cleans stream artefacts; it cannot restore audio that the broadcaster already destroyed. |
| Background playback | Yes, via a Media3 foreground service with a notification. |
| No ads / no tracking | True: no third-party SDKs, no analytics, no accounts. Requests go to the station and (only when you ask) the directory. |

## Permissions

| Permission | Why |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | Streams and directory search. |
| `WAKE_LOCK`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `POST_NOTIFICATIONS` | Keep playing with the screen off, with a notification. |
| `READ_MEDIA_AUDIO` (or `READ_EXTERNAL_STORAGE` on older Android) | Show your local songs. The app works without it — the file picker needs no permission at all. |
| cleartext traffic | Many Tamil FM streams are still plain `http://`; it is declared in the manifest for that reason. |

## Build

Nothing is compiled on the phone. Push to `main` (or an `arena/**` branch), or run
**Actions → Build APK → Run workflow**; the workflow builds all modules, checks the APK contents
(permissions, the Media3 service, the packaged seed list) and uploads the artifacts. Station-list
refreshes are a separate workflow and never touch the app code.
