# Live Guard2.38 — required physical-device validation

This plan is **not an executed test report**. Cloud compilation/JVM/APK checks
cannot prove an audible voice, OEM survival, provider execution, current rating,
message privacy/redaction, widget rendering or a successful phone installation.

Target Redmi13 5G Android16/API36 (record exact ROM), oneAPI26–29 phone such as
OppoA3s, a recent non-Xiaomi manufacturer and both EN/TA settings/font scales.
Keep personal screenshots/messages/audio out of Git and public issue artifacts.

1. **Upgrade/setup:** preserve existing saved OFF/key/language/history choices;
   fresh install stays quiet, no permanent/card/background-Wi-Fi/message enable.
   Reviewed Apply changes only explicitly edited switches. Denied/permanently
   denied/revoked storage/usage/notification/overlay/unknown-apps permission must
   show useful routes/explanations without silently enabling or deleting anything.
2. **Cache/security:** system-default ON only when unset, saved OFF after restart,
   automatic opening/resume refresh, rapid scope changes/cancellation, unreadable
   sizes, no new automatic selections, user-confirmed targeted cleanup only.
   Genuine old review date survives restart/clears; incomplete/future-clock states
   remain historical, not fresh safety claims.
3. **Reader:** multiple chosen apps/sender names, same name in two apps, group title,
   sender-only and explicit full-body per-app; empty sender selection reads nobody.
   Existing notifications not replayed; test fresh/old/future/missing timestamps,
   summary/ongoing/call/progress/aggregate/repost/duplicate/removed notifications.
   Android13+ restricted sideload access/Android16 sensitive-code redaction are
   system controlled. Broad access explanation/revocation and master OFF honored.
4. **Local language/privacy:** EN↔TA body translation; same-language, short/unknown/
   unsupported/emoji-only/sensitive-code cases, model absent/download failure/
   no-Wi-Fi/consent/refusal and language change during queued work. Confirm no
   private content in app prefs/logs/history/AI/report/web/network-TTS paths.
   Operational SDK metadata is not a promise of zero network metadata. Candidate
   names stay bounded session memory; explicit rules clear correctly.
5. **Actual sound:** installed non-network voice missing/present, manual preview
   vs automatic category, two actual distinct previewed A/B answer voices and one
   read each between answers; no replay/cross-voice fallback. Hear the sound, not
   merely a callback. Media mute, quiet hours, DND, Bluetooth/headphones, screen
   off/lock mid-queue/utterance, revoke access/disconnect/config/language changes,
   cold process/force-stop/OEM saver and critical-overheat interruption.
6. **APK update:** current/no-new/daily-OFF/manual/rate-limited metadata, pulsing
   eligible release vs unpublished build. Explicit foreground browser-free download,
   slow/stalled/redirect/cancel/oversize/truncated/digest mismatch; wrong package/
   version/code/certificate and changed installed certificate must not install.
   Private FileProvider scope/grant/cache eviction. Permission decline/return,
   Android installer cancel/fail/succeed. Do not force/bypass or assume Play Protect.
7. **Widgets/unplug:** addBattery/Data/Phone, isolated View choices,2×2/smallest
   resize/font scale/Tamil wrapping/48dp actions, app/device restart. Current raw
   battery percent precision only, genuine observed unplug/%/unknown/clock shift,
   rapid unplug/replug/duplicate receivers and events missed while force-stopped.
   No stamp when simply opening disconnected. Wi-Fi/unlimited user-set/metered/
   missing plan/partial stats. Floating pill's watts/unplug behavior unchanged.
8. **AI/evidence:** chat45 includingweb8, checks/models15, heavy report/device whole90;
   progress/cancel, leave/provider/language/rapid retries/blocked Binder/DNS and
   stale results. One device batch; network-sharing OFF honored, no SSID/new saved
   AI identity guarantees. Invalid/retired model/key/quota/empty/timeout errors
   localized/sanitized. Configured requested ID never becomes execution proof.
   Exact Redmi13 5G current-price no-evidence path; TODAY-local midnight/DST/feed
   dates/dedup/caught-up/no old/fake/publisher ribbon. Estimated age remains.
9. **Rating/help:** official key/site/voice guides never speak secrets or promise
   permanent free quotas. Exact LM Arena category/source/fetched-vs-source dates,
   unknown/routed/no-match/no-network/format/future-clock/staleDecember2025 states;
   no IQ/nearest score/current claim from dated data.
10. **Companions:** Radio playback/folder queue/external EQ, PulseEQ audio/session
    limitations and legacy app startup preserved; karaoke never uploads audio.

Record device/ROM/API/app version/permission/gate/route and actual observed result,
including failures. Avoid copying private contents. Compare release APK version43
and signing identity to CI; unit tests/source declarations alone are insufficient.
